# CodeZenith-style Portfolio — Chintu Chaure

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. Internet is only needed for the Google Fonts import.

## Files
- index.html — complete page structure
- style.css — dark black/purple responsive design
- script.js — loader, mobile menu, scroll animations, CV demo, contact form, AI chat and back-to-top button

## Customize
Search these values in `index.html`:
- `Chintu Chaure`
- `chintu.chaure@example.com`
- `+91 XXXXXXXXXX`
- GitHub link
- Project names/descriptions

For a real CV, replace the demo CV handler in `script.js` with a PDF link.
For a real contact form, connect it to a backend/email service.
